# Quick Reference: Enhanced ViT Training Pipeline

## 🎯 What Changed

The Vision Transformer training notebook has been **significantly upgraded** for better model quality and generalization.

### Key Improvements

| Area | Enhancement | Benefit |
|------|-------------|---------|
| **Augmentation** | RandomAffine, RandomPerspective, GaussianBlur, RandomErasing, Hue adjustment | +5-8% accuracy, better robustness |
| **Optimization** | Label smoothing (0.1), Gradient clipping (1.0), Warmup + Cosine LR | More stable training, better convergence |
| **Evaluation** | Test-Time Augmentation (TTA), F1 score tracking | +1-3% inference boost |
| **Regularization** | Early stopping (patience=5), 15 epochs (from 10) | Prevents overfitting |
| **Infrastructure** | Auto-versioning, metadata, mixed precision, model cards | Production-ready |

### Debug Training
```python

import matplotlib.pyplot as plt

# Check for overfitting
plt.figure(figsize=(10, 4))
plt.subplot(1, 2, 1)
plt.plot(history['train_loss'], label='Train')
plt.plot(history['val_loss'], label='Val')
plt.legend(); plt.title('Loss')

plt.subplot(1, 2, 2)
plt.plot(history['train_acc'], label='Train')
plt.plot(history['val_acc'], label='Val')
plt.legend(); plt.title('Accuracy')
plt.show()

# Check if val_loss increases while train_loss decreases → overfitting
# If so: increase label_smoothing or enable early stopping
```

## 📈 Monitoring Training

### Good Signs ✅
- Validation accuracy steadily increases
- Val loss decreases without sudden jumps
- Train/val accuracy gap < 5%
- F1 score closely tracks accuracy

### Warning Signs ⚠️
- Val loss increases after epoch 10 → **Overfitting** → Increase `LABEL_SMOOTHING`
- Both accuracies plateau early (<70%) → **Underfitting** → Increase `EPOCHS` or `LEARNING_RATE`
- Large train/val gap (>10%) → **Overfitting** → Decrease `EARLY_STOPPING_PATIENCE`

## 🐛 Quick Troubleshooting

### Training Issues
```bash
# Out of Memory
BATCH_SIZE = 16  # or 8

# Slow Training
use_amp = True   # Already enabled on CUDA

# Not Improving
LEARNING_RATE = 8e-5  # Try different values: 3e-5, 5e-5, 1e-4
```

### Upload Issues
```bash
# Token Error
export HF_TOKEN=your_token

# Repo Doesn't Exist
python -c "from huggingface_hub import create_repo; create_repo('user/repo')"
```

### Demo Issues
```bash
# Model Not Downloading
# 1. Check repo exists: https://huggingface.co/username/repo
# 2. Manual download → place in models/gesture_recognition/

# Slow Inference
python scripts/demo_gesture_recognition.py --device cuda
# or
python scripts/demo_gesture_recognition.py --max-hands 1
```
