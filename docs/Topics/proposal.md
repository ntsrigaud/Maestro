# Project Proposal

## Research Topic:

- Computer Vision/Pattern Recognition

## Research Motivation:

- A natural and convenient way to communicate with laptops.
  - Implement the mouse capabilities through hand gestures.
- Limitations from previous HAVIT researches
  - Latency / Real-time performance
  - Data scarcity not fully solved
  - Environmental sensitivity
  - User Variability
  - Energy and Hardware cost
  - Limited Gesture Vocabulary

## Related Work:

[Research Paper](https://www.nature.com/articles/s41598-025-10758-9)

## Problems and Solutions:

Unlike a traditional mouse, gesture based input:

- Removes the need for constant hand repositioning
- Reduces strains from repetitive movements
- Making it more comfortable for long term use
- Enables touch free control:
  - Cleaner in shared or sterile environments
- Opens accessibility for people for mobility limitations
- Unlock faster multitasking and immersive interactions
  - Creative tasks
  - Gaming
  - VR
  - Where traditional input devices feel restrictive

## Expected Results:

- Fully working prototype system that performs the same functionalities as the mouse on the computer, but more conveniently.
