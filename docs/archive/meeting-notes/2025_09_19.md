## Discussions

- Difference between system being developed and existing systems.
  - existing systems track hand landmarks.
  - our system tracks hand motions
- Technologies:
  - ViT -> static gestures
  - LSTM -> Memory
  - ALBEF -> Meaning
  - HAVIT -> Use less training data
- No direct mapping
  - There is no need to directly specify what exact motion needs
    to be done to map to a certain command.
  - A motion is performed, the meaning is interpreted. Using the
    interpreted meaning, it is mapped to the closest matching meaning.
  - Moves away from static/hardcoded trained gestures.
  - Easier way to add new gestures -> add the semantic meaning.
- How to stop unintentional inputs?
  - Use eye tracking?
- Implementation platform
  - Linux
  - system level
    - The application software determines what the input does.
    - Swipe left is swipe left...it is not mapped to go
      backwards/rewind.
