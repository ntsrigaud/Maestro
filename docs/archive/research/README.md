## Why Archived

**HaGRID Dataset Not Used in Current System**

The current semantic system uses **pretrained CLIP** and does not require:

- Training data
- Dataset downloads
- Class-specific annotations

HaGRID was explored during the classification approach phase (see [archive/training/](../training/)).
